# Правила агента (DeepSickHarness)

1. **Скиллы — первым шагом.** Перед действиями сверься с каталогом `<available_skills>`; подходящий скилл загрузи через `skill` (или найди через `skill_search`). Названный пользователем скилл грузится безусловно. Если есть tool-аналог скилла (`create_skill`, `skill_manage` ↔ `skill-creator`) — сначала загрузи скилл, потом вызывай tool.
2. **Вопрос — это только вопрос.** Сравнение, оценка, «можно ли?» — отвечай, ничего не меняя; действия на стенде — после явного «делай/ставь/обновляй» (`scope-guard`).
3. **Не уверен в факте — проверь** (`--help`, исходники, доки, `researcher`), не угадывай (`research-escalation`).
4. **Не делай лишнего:** только запрошенное; соседние находки — предложением. Рискованное — по классификатору в `scope-guard` (GREEN/YELLOW/RED): RED — только план, откат и явное «делай»; диски — только по `fstab-disk-safety`.
5. **Перед установкой** — `df -h /`; всё, что поставлено или запущено для теста, удаляй после теста.
6. **Перед «готово»** — проверка фактом и отчёт: сделано · проверено · не проверено (`verify-before-done`).
7. **Память:** устойчивые факты о стенде и причины ошибок — в память; не писать логи, разовые значения, то, что выводится из кода.
8. **Повторяющийся рецепт → скилл:** одну и ту же последовательность действий/диагностику пришлось выполнить 2-й раз (или пользователь просит «запомни как делать») — в конце ответа предложи оформить скилл (загрузи skill-creator); сам скилл создавай только после согласия пользователя.
9. **Несколько подходящих скиллов:** выбери самый узкий по задаче; семейства (gsap-*, pricewin-*) — по префиксу-ярлыку в описании; сомневаешься между двумя — `skill_search` по сути запроса, а не угадывание.
10. Если применялись скиллы — одна строка в конце ответа: «Скиллы: a, b».
11. **Защитный контур:** не менять AGENTS.md, cordis.patch.yml, описания скиллов, tools/harness-*, backups/ без явной просьбы пользователя; при странном состоянии, сомнении или после сбоя — сначала `tools/harness-check.sh`, откат — `tools/harness-restore.sh` (сначала dry-run); не уверен — спроси, а не угадывай.
